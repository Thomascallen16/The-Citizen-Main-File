# CIT Site

This repository is the consolidated source workspace for the CIT site project. It has been initialized to receive the project's application code, documentation, design assets, and deployment configuration.

## Repository structure

| Path | Purpose |
|---|---|
| `src/` | Application source code and reusable components. |
| `public/` | Static assets served with the site. |
| `docs/` | Project documentation and implementation notes. |
| `assets/` | Source design assets and non-runtime media. |

## Getting started

Project materials will be organized into the directories above as they become available. The repository currently provides a clean, version-controlled foundation for the consolidated work.
